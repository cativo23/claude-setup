## Git Defaults

- Use conventional commits: `type(scope): description` (feat, fix, docs, refactor, test, chore)
- PR titles: imperative mood, under 70 characters
- Branch naming: `type/short-description` (feature/, fix/, docs/, refactor/)
- Commit messages: focus on WHY, not WHAT (the diff shows the what)
- One concern per commit — don't mix refactoring with features
